# FileCopyHtml

複数のフォルダから選んだファイルを、**1つの目標フォルダへ一括コピー**するブラウザアプリです。
サーバー構築もインストールも不要で、Chrome / Edge で `index.html` を開くだけで動きます。

🌐 **公開版（GitHub Pages）**: <https://pppp314592.github.io/FileCopyHtml/>

---

## 特徴

- **コピー先 1 つ ＋ ソースフォルダ 3 つ**（最大 12 つまで追加可能）
- コピー先とコピー元を **1つのファイル一覧にまとめて表示**し、そのまま複数選択してコピー
  - コピー先は上書き判定のために表示するだけで、**参照のみ（選択不可）**
  - 選択してコピーできるのはコピー元のファイルだけ（件数がそのまま実行件数になります）
- 各ファイルに状態タグを付与（`新規` / `上書き` / `コピー先`）→「コピー先に同名がないものだけ」を一瞬で絞り込み
- **コピーボタン 1 クリックで実行、既存ファイルは自動上書き**
- サブフォルダ構成の保持 / フラット化の切替、上書きの ON・OFF
- 8 MB 単位のチャンク書き込み、進捗バー、**中断**、ファイル単位の結果ログ
- フォルダ位置を **ini ファイル**に記録し、起動時に**自動読み込み**
- フォルダ選択結果は**パス欄へ自動反映**（要確認として色付きで表示）
- **ネットワーク共有（UNC パス）に対応**
- 依存ライブラリ 0（Vanilla JS）

## 動作環境

| | |
|---|---|
| ブラウザ | **Google Chrome / Microsoft Edge 86 以降**（File System Access API が必要です） |
| OS | Windows / macOS / Linux |
| その他 | サーバー不要・ビルド不要 |

> Firefox / Safari は File System Access API に未対応のため、フォルダ選択できません（画面右上のバッジに「非対応」と表示されます）。

## 使い方

### 1. 起動

- `start.cmd` をダブルクリック
- または `index.html` を直接ブラウザで開く
- または公開版の URL を開く: <https://pppp314592.github.io/FileCopyHtml/>

### 2. フォルダを指定

| 枠 | 役割 |
|---|---|
| **DEST** | コピー先（目標フォルダ）。ここへコピーされます |
| **S1 / S2 / S3** | ソースフォルダ（コピー元）。`＋ ソースフォルダを追加` で増やせます |

各枠の **「選択…」** から Chrome のフォルダダイアログで指定します。
初回のみブラウザの許可ダイアログが表示されます。

#### パス欄への自動反映

ブラウザの仕様上、フォルダ選択時に取得できるのはフォルダ名だけ（フルパスは不可）です。
そのためパス欄は次のように自動で更新されます。

| 状況 | パス欄の挙動 |
|---|---|
| パス欄が空 | フォルダ名で初期化し、**要確認**（オレンジ色）にする |
| 末尾が同じフォルダ名 | そのまま維持する（要確認も解除） |
| 末尾が違う | **末尾だけ差し替える**（例 `\\srv\share\old` → `\\srv\share\new`）＋要確認 |

ブラウザ API で取得できないため、`\srv01\share` の頭部分は推測できません。
パス欄は実際に使う場所（例 `\\srv01\share\dest`）へ書き換えてください。
区切りを含むパスに書き換えると要確認表示は自動的に解除されます。

> パス欄の内容は ini に記録されます。ini のパスは記録用であり、アクセス権には影響しません。

#### 再スキャン

フォルダ枠ごとの個別ボタンはなく、**「全フォルダを再スキャン」** 1 つのみに統一しています。
（フォルダを 1 つだけ再走査したい場合は、「選択…」から選び直してください）

### 3. ファイルを選んでコピー

1. 一覧でファイルをクリック（または「表示中を全選択」「コピー元のみ選択」など）
2. **「コピー実行（N 件）」** を押す
3. 進捗バーとログで結果を確認（`Ctrl+Enter` でも実行できます）

### Network / UNC パス

パス欄は ini に記録される文字列で、フォルダダイアログの初期位置にもなります。

- UNC の共有: `\\サーバー\共有\dest`
- マップドドライブ: `Z:\dest`
- ローカル: `C:\Data\dest`

> ブラウザ側で UNC 共有を直接選べない場合は、`net use Z: \\サーバー\共有` でドライブを割り当て、そのドライブから選択してください。

## 設定ファイル（config.ini）

右上の **「config.ini を選択…」** で任意の ini ファイル（`settings.ini` など名前も場所も自由）を紐付けると、
起動時に自動で読み込まれ、フォルダやオプションの変更のたびに自動保存されます。

```ini
[FileCopyHtml]
Version=1
Destination=\\srv01\share\dest
Source1=\\srv01\share\in1
Source2=C:\data\in2
Source3=
KeepTree=true
Overwrite=true
```

| キー | 意味 |
|---|---|
| `Destination` | コピー先の記録パス |
| `Source1` … `Source12` | ソースフォルダの記録パス（空欄可） |
| `KeepTree` | `true` でサブフォルダ構成を保持 / `false` でフラット化 |
| `Overwrite` | `true` で既存ファイルを上書き |

### ini ファイルの扱いについて（重要）

- **公開リポジトリ・GitHub Pages 上の `config.ini` はアプリに読み込まれません。**
  アプリはローカルファイルを一切ダウンロードしません（`fetch` などの通信はゼロです）。
  読み取るのは「config.ini を選択…」で自分で紐付けたローカル上のファイルだけです。
- ini に書いたパスは**記録用**であり、アクセス権の制限ではありません。
  実際にファイルを操作するには、各枠の「選択…」からブラウザに許可する必要があります。
- `config.ini` に自分の環境パス（例 `\\社内サーバ\共有`）が書き込まれるため、
  **公開リポジトリへ commit しない運用**にしたい場合は `.gitignore` に `config.ini` を追加してください。
- ini を扱えない環境向けに「ini 編集…」からテキストを直接編集し、ダウンロードすることもできます。

## 制限・注意

- 初回はブラウザの許可ダイアログ（読み取り / 書き込み）が必要です。
- ブラウザを再起動するとフォルダのアクセス権がリセットされるため、
  「**保存済みフォルダの権限を要求**」を 1 クリックします（再度の走査が自動再開します）。
- `file://` で開いた場合は環境によってフォルダ選択結果の保持（IndexedDB）が使えないことがあり、
  その場合は毎回フォルダを選び直す必要があります。**https 経由（GitHub Pages など）で開くほうが確実**です。
- コピー先ファイルの**更新日時・属性は保持されず**、コピー実行時刻になります。
  File System Access API にはファイル時刻を設定する API が存在しないため、
  **ブラウザのみで実装する限り回避できません**（保持させたい場合は PowerShell / Node 等の
  バックエンドでコピーする実装に変更する必要があります）。
- 1 フォルダあたり 20,000 ファイルまで走査します（超分はログに警告）。
- 同じコピー先パスが複数のソースに存在した場合は**後勝ち**で上書きされます（ログに警告）。

## ファイル構成

```
index.html        UI
config.ini        設定ファイル（フォルダ位置など）
start.cmd         起動用
css/styles.css    スタイル（ライト / ダーク対応）
js/config.js      INI の解析・生成、設定の永続化（IndexedDB / localStorage）
js/folder.js      フォルダ選択・権限確認・再帰ファイル列挙
js/copy.js        コピーエンジン（チャンク書き込み・進捗・中断）
js/app.js         UI 配線（一覧・複数選択・実行制御）
要件.txt           元の要件
```

変更後はブラウザのキャッシュを回避（`Ctrl+Shift+R`）して確認してください。
